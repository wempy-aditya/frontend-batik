**Dokumentasi untuk AI Video Editor – Batik AI Studio Tutorial (Loop Exhibition)**  
Tujuan: video tutorial yang diputar berulang di pameran, menjelaskan alur penggunaan dari Stage 1–4.  
Target audiens: pengunjung umum, tidak harus teknis.  
Bahasa: Indonesia, gaya ramah dan jelas.  
Tone: edukatif, percaya diri, singkat, tidak terlalu teknis.

---

**1) Struktur video & durasi**

- Total video: 4.5 menit (sesuai 5 putaran demo).
- Pola: Intro singkat → 5 loop demo (skenario berbeda) → outro singkat.
- Loop harus rapi: akhir video disesuaikan agar bisa seamless ke awal (fade‑out singkat / frame ending mirip opening).

---

**2) Visual yang wajib ditampilkan**

- Stepper di atas (Stage 1–4).
- Stage 1: input prompt, opsi scenario, tombol Random Prompt, hasil motif, pilih 2 motif.
- Stage 2: input grid rows/cols (harus genap), ukuran kain, DPI, tombol Compose Fabric.
- Stage 3: preview kain + summary parameter, tombol zoom preview.
- Stage 4: opsional prompt FLUX (tombol Add Prompt), pilihan style/gender/sleeve, Generate Result, preview hasil + zoom + Download.
- Agent History (boleh ada, tapi jangan terlalu dominan).
- Hindari menampilkan error (potong bagian error).

---

**3) Script narasi (voice over) per bagian**

**Intro (10–15 detik):**  
“Selamat datang di Batik AI Studio.  
Di sini kita bisa membuat motif batik dari teks, menyusun kain, lalu menghasilkan tampilan batik pada busana.  
Mari kita lihat alurnya dari Stage 1 sampai Stage 4.”

**Stage 1 – Generate Motifs:**  
“Stage 1 adalah pembuatan motif dari prompt.  
Kita bisa menulis prompt sendiri atau memakai tombol Random Prompt.  
Pilih skenario, tentukan jumlah motif, lalu klik Generate Motifs.  
Setelah hasil muncul, pilih tepat dua motif untuk melanjutkan.”

**Stage 2 – Compose Fabric:**  
“Stage 2 menyusun dua motif menjadi kain.  
Masukkan jumlah grid baris dan kolom yang **harus genap**, lalu atur ukuran kain dan DPI.  
Klik Compose Fabric untuk membuat pola kain checkerboard.”

**Stage 3 – Fabric Summary:**  
“Stage 3 menampilkan ringkasan kain.  
Di sini kita melihat preview kain dan parameter yang dipakai.  
Kita bisa klik tombol zoom untuk melihat detail kain lebih besar.”

**Stage 4 – Apply FLUX:**  
“Stage 4 menerapkan kain ke busana menggunakan FLUX.  
Prompt tambahan bersifat opsional dan bisa ditampilkan dengan tombol Add Prompt.  
Pilih style, gender, dan sleeve, lalu klik Generate Result.  
Hasil bisa dizoom dan diunduh.”

**Outro (5–10 detik):**  
“Itulah alur Batik AI Studio.  
Dengan empat tahap sederhana, motif batik dapat dibuat hingga menjadi visual busana yang siap dipamerkan.”

---

**4) Subtitle (SRT) dan On‑Screen Text**

- Subtitle: ikuti narasi di atas, 1–2 baris per kalimat.
- On‑screen callout singkat (overlay kecil):
  - “Pilih 2 motif”
  - “Grid harus genap”
  - “Compose Fabric”
  - “Zoom preview”
  - “Generate Result (FLUX)”
  - “Download hasil”

---

**5) Perbedaan 5 putaran demo (variasi skenario)**  
Gunakan 5 loop demo yang mirip, tapi dengan variasi berikut supaya terlihat kaya:

- Loop 1: Prompt dari Random Prompt, Scenario `scenario2`, style `kemeja`, gender `pria`, sleeve `panjang`.
- Loop 2: Prompt manual, Scenario `scenario4_1`, style `batik`, gender `wanita`, sleeve `pendek`.
- Loop 3: Prompt Random, grid sedikit lebih besar (misal 12x12), style `casual`.
- Loop 4: Prompt manual lebih pendek, grid lebih kecil (10x10), hasil difokuskan pada zoom kain.
- Loop 5: Prompt Random, tekan Add Prompt di Stage 4 untuk menunjukkan prompt opsional.

---

**6) Saran editing untuk loop pameran**

- Tambahkan musik latar low‑volume, tidak dominan.
- Transisi halus antar stage (fade cepat, 0.3–0.6s).
- Jangan terlalu lama di satu stage (ideal 8–15 detik per stage).
- Hindari tampilan loading terlalu lama; jika ada, dipercepat 1.5–2x.
- Pastikan loop terakhir berakhir dengan tampilan yang mirip opening agar seamless.
